## CORRECTION — sin/cos on GPU (affects v0.7.17 through v0.7.23)

sin/cos on GPU for 1e4<=|x|<1e7 returned silently wrong values from
v0.7.17 through v0.7.23 (max abs error up to 0.6); fixed in v0.7.24
(accurate to 5e5, NaN beyond); affected Kokoro voice output and any
large-argument trig. The same correction line is appended to the
v0.7.17–v0.7.23 release notes.
