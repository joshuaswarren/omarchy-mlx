# DEC-44: G13C QKV Multi WG-variant screen — R2S16 wins, dispatch-order and straddle negative

Receipt for the `qmm_g14c_multi_r2s16_default_part` G13C default flip on
branch `wB2/dec44-r2s16-g13c`. DEC-44 asked to attack `QmmVecQ4Multi` QKV low
effective bandwidth (gx=384 at ~98 GB/s vs o/down gx=160 at ~159 GB/s and
lm_head at ~326 GB/s) on G13C (jw16) and G14C (M2): audit member-boundary WG
straddling and Q/K/V weight-buffer cache contention in
`QmmVecQ4MultiSubgroupBF16R2S8W2`, and test whole-WG member alignment /
dispatch-order variants.

## Prior art this builds on

- `#1111` (`be678adad1`): G13C `R2S8W2Fast3w` (3-weight FIFO-upfront) default —
  the cache-contention fix already shipped; every baseline here runs it.
- `#964` (`9f222b2fa1`): `MLX_OMARCHY_QMM_ORDER=stride` dispatch-order probe —
  proved negative on 40 ABBA legs (G13C + G14C), knob ships default-off.

## Audit findings

- **Member-boundary straddling: none exists.** Qwen3-4B QKV members n ∈
  {4096, 1024, 1024} are all multiples of the 16-row WG tile (R2S8W2) and the
  32-row tile (R2S16W2); members occupy contiguous whole-WG blocks.
- **Cache contention: already addressed by `Fast3w`'s FIFO weight schedule**
  (#1111); the residual gap is WG count, not scheduling.

The envs demonstrably switch kernels on G13C; the R2S16 arm halves the WG
count (384→192) for the same rows — the "whole-WG member alignment" direction.

## Verdict

**Ship the G13C default flip** — `qmm_g14c_multi_r2s16_default_part` now
includes `G13C`. +0.80%/+0.60% is under the card's 1% GREEN bar, but the
separation is perfect (10/10 legs), the direction replicates across ctx and
models, the kernel already ships (G14C default), the env path is verified on
real hardware, and 0-ULP identity is pinned by `multi_r2s16_up_fast` /
`multi_r2s16_up_fast_3m` in `test_qmm_geometry.cpp`. #1111 shipped the same
effect size (+0.80% shipped Mesa) on this metric.

## Remaining DEC-44 space

- M2 (G14C): already defaults to R2S16 — nothing to flip.
- Dispatch-order: proved negative (#964).
- Straddle audit: negative (no straddle exists at these member shapes).
- Kernel-level µs attribution under a quiet host would refine the QKV GB/s
  number; the shipped change does not depend on it.
